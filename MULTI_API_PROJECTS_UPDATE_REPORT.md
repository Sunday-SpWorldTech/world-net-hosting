# Reseller Multiple API Projects Update

- Resellers can create multiple named Domain API or Banking API projects.
- Each project can store independent test and live credentials.
- Test/live keys remain attached to that project until the reseller deletes them.
- Copy and delete controls are available per project and environment.
- Entire projects can be deleted with confirmation, removing their credentials.
- Existing account-wide reseller keys are migrated automatically into a "Legacy API Project" without losing access.
- API authentication resolves the exact owning reseller and project.
- Reseller dashboard responses no longer expose credential hashes.
- Desktop design was preserved; mobile controls stack responsively.
